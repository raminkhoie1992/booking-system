# Booking System

A simple appointment booking system — learning project.

## ⚠️ Status

This project is under active development. Current phase: core logic in vanilla JavaScript. Next phases: TypeScript migration, Express API, database integration, testing, and Docker.

## Features (Current)

- Create appointments with name, date, and time
- Prevent double booking for the same time slot
- Return structured response for each booking attempt

## How to Run

```bash
node src/booking.js
